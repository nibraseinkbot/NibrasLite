Selenium 4 Helper Persistent Session Light Stealth Any Website
لماذا؟ الملفات البداية السريعة كيف تعمل واجهة المكتبة البروكسي أوامر REPL الـ Stealth إثبات الإعدادات

لماذا هذه المكتبة؟

سيلينيوم الطبيعي يُشغّل المتصفح ثم يُغلقه عند انتهاء السكربت. هنا نعكس الفكرة: المتصفح يُشغّل كـعملية مستقلة، وكل سكربت لاحق يتعلّق به ولا يملكه — فيبقى حياً.
ملاحظة: نبراس الخفيف أداة مساعدة خفيفة لسيلينيوم تضيف ميزات قليلة للتخفي (stealth ضعيف غير مُجرب ضد أنظمة كشف قوية)، وليست بديلاً قوياً ضد أدوات الكشف المتقدمة.

♻️ لا يُغلق أبداً

تُضيف سطر سيلينيوم جديداً وتُكمل على نفس النافذة.

🍪 كوكيز وأدوات

حفظ/حقن/تصدير الكوكيز، وحفظ تسجيل الدخول.

🥷 مقاومة كشف

حتّى navigator.webdriver يظهر مخفياً.

🌐 أي موقع

لا شيء خاص بـCrashlytics — عام بالكامل.

البداية السريعة

1) افتح الجلسة مرّة واحدة (تبقى مفتوحة)

python sel_nibras\browser.py start --url https://any-site.com
🕵️ User-Agent مخصص: من الطرفية browser.py start --ua "Mozilla/5.0 (…)" أو من بايثون browser.ensure(url, ua="Mozilla/5.0 (…)"). ويمكنك تمرير أي أعلام كثيرة عبر extra_args=["--window-size=1400,900"].

2) أكمل عليها وقت ما تشاء (REPL)

python sel_nibras\browser.py attach
للتعلّق من سكربت بايثون بدل الـREPL: 
import browser
d = browser.ensure()                 # نفس نافذة Chrome المفتوحة
browser.click(d, "#save-button")     # سطر جديد... بلا إغلاق أو إعادة فتح

الإيقاف

# quit داخل REPL = انفصال فقط (المتصفح يبقى)
python sel_nibras\browser.py stop    # إغلاق فعلي لنسخة هذا الملف فقط

كيف تعمل الفكرة؟

browser.py start ➜ Chrome منفصل (منفذ 9222 + ملف دائم) ➜ attach عبر debuggerAddress ➜ السكربت ينتهي… والمتصفح يبقى

المفتاح: Selenium لا يملك المتصفح عند التعلّق، بل يتصل به عبر بروتوكول CDP. لذلك انتهاء السكربت = قطع الاتصال فقط، لا إغلاق المتصفح.

🧱 كائن Browser (يُمرّر كل واجهة سيلينيوم)

import browser
from browser import Browser, By

b = Browser.ensure("https://x.com")
b.find_element(By.ID, "q")     # دالة سيلينيوم أصلية (يُمرّرها تلقائياً)
b.click("#go")                 # دالة المكتبة
b.driver                       # WebDriver الخام بالكامل

المكتبة تُعيد تصدير واجهة سيلينيوم كاملة، فتكفيك هذه السطور:

from browser import webdriver, By, Keys, Select, ActionChains, WebDriverWait, EC

🔗 البروكسي (Proxy)

دالة رئيسية واحدة proxy_check(add, port, username, password) تقوم بكل شيء: تكتشف نوع البروكسي تلقائياً، تحدد البلد، تحقن اللغة والمنطقة الزمنية المناسبة.

الواجهة البسيطة (كما طلب نبراس)

import browser

# الاستخدام الأساسي — يدخل host + port
r = browser.proxy_check("1.2.3.4", 8080)
print(r["type"], r["country"], r["lang"], r["timezone"])

# مع مصادقة
r = browser.proxy_check("1.2.3.4", 8080, username="user", password="pass")

# أنواع البروكسي الأربعة (كلها تستخدم proxy_check داخلياً)
browser.proxy_http("addr", 8080)
browser.proxy_https("addr", 443)
browser.proxy_socks4("addr", 1080)
browser.proxy_socks5("addr", 1080)

# دالة الجمع
browser.proxy_combine("socks5", "5.6.7.8", 1080)

ماذا ترجع proxy_check؟

الحقلالوصف
typeنوع البروكسي المكتشف: http / https / socks4 / socks5
countryالبلد المستنتج من الـ IP (مبسّط حسب النطاق)
langاللغة المطبوعة تلقائياً حسب البلد
timezoneالمنطقة الزمنية المناسبة للبلد
speedسرعة الاتصال: fast / medium / slow
worksهل البروكسي يعمل؟ (True / False)
anonymityمستوى الخصوصية: high / medium / low
optionsChrome options جاهزة للتطبيق
errorرسالة الخطأ إن فشل الاتصال

مثال عملي كامل

import browser

# 1. افحص البروكسي
info = browser.proxy_check("1.2.3.4", 8080)
print(f"النوع: {info['type']} | البلد: {info['country']} | اللغة: {info['lang']}")
print(f"المنطقة: {info['timezone']} | السرعة: {info['speed']}")

# 2. طباعة تقرير أنيق
print(f"  النوع:    {info['type']}")
print(f"  البلد:    {info['country']}")
print(f"  اللغة:    {info['lang']}")
print(f"  المنطقة:  {info['timezone']}")
print(f"  السرعة:  {info['speed']}")
print(f"  يعمل:     {'نعم' if info['works'] else 'لا'}")
print(f"  الخصوصية: {info['anonymity']}")

# 3. طباعة الحالة كاملة
print("تقرير بروكسي كامل:")
for k, v in info.items():
    print(f"  {k}: {v}")

# 4. تطبيق على المتصفح (اختياري - يمكنك استخدام options في start/ensure)
driver = browser.ensure(options=info["options"])
💡 البروكسي الأمريكي: لو كان البروكسي أمريكي (IP يبدأ بـ 1-49)، ستجد country=US و lang=en و timezone=America/New_York.
يمكنك تجاوز اللغة يدوياً عبر تمرير lang="ar".
